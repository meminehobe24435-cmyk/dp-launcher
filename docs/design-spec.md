# 设计规格（从参考图量出来的数值）

本文件记录每个界面数值的**来源**：是直接从参考图量到的，还是用 `tools/calibrate.py` 拟合出来的。
运行 `python tools/export_tokens.py` 会把这里的量生成预览用的 CSS 变量；
Android 端则通过这些常量（`DesignSpec.kt`）经 `UiScale` 折算。

参考图画布：**1280 × 720**（16:9）。以下数值单位都是"参考像素"，即 1280×720 画布上的像素。

## 3. 倒影

| 项 | 值 | 来源 |
|---|---|---|
| 可见高度 | 50 | 参考图卡片下方 y 430→480 渐隐结束 |
| 起始 alpha | 0.60 | 解 `color = a·card + (1−a)·wallpaper`：y=433 处 a≈0.60，线性衰减 |
| 与卡片间隙 | 0 | 镜面直接接在卡片下边缘 |

实现：`ReflectionContainer` 把子 View 栅格化一次（内容变化才重绘），
再用 `translate + scale(1,-1)` 镜像绘制，并用 `DST_IN` 竖直渐变遮罩做渐隐。
HTML 预览用同一套算法（`transform: scaleY(-1)` + `mask-image` 渐变）。

## 6. 缩放规则

```
scale   = min(screenWidth / 1280, screenHeight / 720)
px      = 参考像素 × scale
垂直居中偏移 = (screenHeight − 720 × scale) / 2
```

- 720p 投影仪（1280×720，density 1.0）：scale = 1，与参考图逐像素一致。
- 1080p / 4K：整体等比放大；非 16:9 屏幕（如 16:10）上下留边并居中，不会溢出。
- 文字用 `COMPLEX_UNIT_PX` 直接给像素值，因此不受系统字体缩放影响 —— 桌面 UI 的一致性优先。

## 7. 已知不可复刻项

| 现象 | 原因 |
|---|---|
| 参考图顶部红色批注、紫色框 | 需求方在截图上做的批注浮层，不属于产品 UI |
| Netflix / YouTube / Google Play 字标宽度 | 参考图用的是各品牌定制字标，同一系统字体无法同时匹配（"chrome" 已完全吻合） |
| 参考图边缘的暗色晕圈 | 低分辨率截图的 JPEG 振铃，不是真实投影效果 |
